# ZELUX-DL Product Context

## Register
Product

## Product Purpose
ZELUX-DL is a Windows download manager paired with a browser extension. Users can collect links in the browser and hand them to the local ZELUX-DL executable for downloading.

## Users
The primary user is a Windows desktop user who wants to capture links from a browser and continue the download in ZELUX-DL. The extension must make the local-app connection explicit and understandable.

## Product principles
- Make setup and download actions clear, short, and reversible.
- Require an explicitly configured local `ZELUX-DL.exe` path before sending links.
- Never imply that the extension can execute or inspect arbitrary local files; explain when app handoff is unavailable.
- Preserve the established dark, violet visual identity while maintaining readable contrast and accessible focus states.
- Keep controls inside their panels, avoid overlap, and prefer working, current status over decorative or fabricated telemetry.

## Interface tone
Modern, capable, direct, and calm. Use concise Thai-first guidance with technical paths shown plainly. Errors should say what happened and the next useful action.
