ZeluxDL browser extension
========================

Install the desktop app first, then download and extract the matching browser
extension archive from https://github.com/SMOKEx2/Zelux-DL/releases/latest.

  Chrome / Edge / Brave / Opera / Vivaldi / Chromium
    Open the browser extensions page, turn on Developer mode, and choose
    "Load unpacked" for the extracted Chromium extension folder.

  Firefox / Zen
    Open about:debugging#/runtime/this-firefox, choose "Load Temporary Add-on",
    and select manifest.json in the extracted Firefox folder. Firefox forgets
    temporary add-ons on restart.

ZeluxDL registers its native messaging host automatically. Open Settings ->
Browser integration to check the connection or repair it.
